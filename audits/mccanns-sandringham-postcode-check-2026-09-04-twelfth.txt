FIX
  tools/check-postcodes.js: new top-level aliasOf(b), cached per branch,
  derived from data rather than a hand-written per-branch list:
    stem = brandLabel with a trailing "Chemist"/"Chemists"/"Pharmacy" dropped
    town = the town word branchName itself already carries, for the six
           shared-brand branches where branchName = brandLabel + " " + town
           (so mccanns_sandringham resolves via its OWN branchName's
           "Sandringham", not the current seoTown "St Michael's" - seoTown
           moves per item 5.7, branchName's town word does not); otherwise
           seoTown, for the ten branches whose branchName carries no town.
    alias = stem + " " + town, or null if either half is missing.
  Rule 6's per-line branch-naming test now matches EITHER branchName OR
  aliasOf(b), deduped by branch id so the same branch is never counted twice
  on one line.

  aliasOf() output verified directly for all 16 branches: 15 non-null,
  pairwise distinct, matching the real usage above exactly (Scorah Bramhall,
