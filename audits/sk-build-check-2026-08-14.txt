Build Pack v2 section 5.1: "anything that must RANK has to be real text in the
page, not injected by JavaScript". check-contraception-copy.js read the page
through visible(), which strips HTML comments but NOT <script> bodies. Copy
moved out of the body into a script that writes it back with innerHTML
therefore satisfied every presence rule while being absent from the page as
far as Google is concerned.

PROVED BY INJECTION, NOT BY READING
The four hero-points on contraception-sk-chemists-bootle.html, one of which is
"Free NHS service, confidential consultation", were replaced by an empty div
plus a script assigning the identical markup to innerHTML via a backtick
template literal, so the markup inside the script was byte-identical to the
markup it replaced. Against the OLD checker: check-contraception-copy passed,
and all 36 checkers stayed green. The same block wrapped in an HTML comment
failed immediately on all four lines. That contrast is what proves the hole
was the script half only, and that the comment half was already covered.

An earlier version of the injection escaped double quotes for a JS string
literal, which broke one of the four lines on its own and made the checker
fail for the wrong reason. That first result was discarded and the injection
redone with a backtick literal. Recorded because a mutation that fails for the
wrong reason looks like a passing test.
