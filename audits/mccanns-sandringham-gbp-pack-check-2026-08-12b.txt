THE FIX
Rule 9 added to check-pharmacy-first-eligibility.js, which is where the
clinical numbers already live, so the cohorts are not duplicated into a second
file. It reads every pack in gbp-packs/ (TEMPLATE.md excluded), sentence by
sentence, and fails any age that is not part of a pinned NHS cohort. Matching
is by whole cohort PHRASE, not by bare number, so a correct number attached to
the wrong service fails too. Sentence-bounded, so a cohort named next door
cannot excuse an age here. The NHS blood pressure cohort is now pinned
alongside the seven Pharmacy First pathways.

Two false positives surfaced on the first run of the rule and both were rule
defects, not data defects, so the rule was corrected and neither pack touched:
  - sk-chemists-bootle.md writes "aged 40 or over". A legitimate variant of
    the same cohort; the phrase now accepts "and over" and "or over".
  - riddings-timperley.md quotes an H1 promising a switch in "under 30
    seconds". A duration, not an age. A number carrying a unit is no longer
    read as an age. Ages in these packs are always written "aged N", which
    the unit guard never suppresses.
