THE ONE REAL DEFECT, IN REPO, FOUND AND FIXED
tools/check-travel-clinic-copy.js stripped <script> bodies CASE-SENSITIVELY:
    .replace(/<script[\s\S]*?<\/script>/g, " ")
This is the third instance of the class the 193rd and 194th runs closed on
check-switch-copy.js and check-contraception-copy.js. Those two had no script
stripping at all. This one did, so it read as already covered and nobody
re-examined it. Uppercase <SCRIPT> survived the strip, and copy hidden inside
one counted as visible.

  - lowercase <script>, old checker: FAIL. This is the control, and it is what

THE FIX
visible() now strips scripts with /<script\b[\s\S]*?<\/script>/gi, matching
the two checkers already hardened, with a comment recording why the case flag
is the point. plain() inherits it, so the sentence-level rules including the
[private] rule are covered too.

DELIBERATELY NOT CHANGED
tools/check-weight-loss-copy.js uses /<script[\s\S]*?<\/script>/gi. It is
already case-insensitive and so does not carry this defect. It lacks the \b,
which can only cause over-stripping, never the under-stripping that hides
copy, so it was left alone rather than widened on a pass that did not need to.
