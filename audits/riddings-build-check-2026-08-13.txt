FINDING B (a fault in THIS run's own work, written up rather than dropped)
The first version of this run's POM extractor pulled quoted words out of
pom-names.js with a general regex and did not strip the file's comments first.
It therefore loaded the words the file's own prose quotes as EXAMPLES, and
reported 12 false failures for the "medicine" usually. The irony is exact: the
sentence it misread is the one explaining that word-boundary matching stops
"alli" firing inside "usually". The extractor now strips block and line
comments first, parses only the five named array literals, and stops the run
outright if any group parses empty, so a silently empty POM list cannot ever
present itself as a clean page. 82 names loaded: weight loss 21, Pharmacy
First 8, contraception 2, travel vaccines 36, antimalarials 15.
