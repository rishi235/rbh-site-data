Not on record anywhere (confirmed by re-reading all seventeen prior passes'

branches all follow the same shape, `return bN && { ... }`, where bN comes
from branchOf() -> bySlug[brandSlug-townSlug]. bySlug is built by:

    data.branches.forEach(function (b) {
      if (b.disposed || !b.brandSlug || !b.townSlug) return;
      bySlug[b.brandSlug + "-" + b.townSlug] = b;
    });

So a filename that MATCHES one of the seven page-type regexes (unlike the
9th/11th passes' "totally unrecognised" file, which matches none of them) but
whose slug resolves to a DISPOSED branch, or to no branch at all, falls
through the matched `if` block's own `return bN && {...}` to null, and the
file becomes untyped via the same "if (!exp) { untyped.push(file); return; }"
path. This is the exact mechanism that has to work correctly the day a live
branch is disposed and its generated pages are not immediately deleted -
precisely what happened with Wilmslow (disposed 1 July 2026, per CLAUDE.md
and Q2's answer "Remove Wilmslow from branches.json and take its pages
down"). branches.json today carries no live Wilmslow record to reuse for the
test (Q2 removed it outright rather than flagging it disposed:true), so this
pass builds a synthetic equivalent instead.
