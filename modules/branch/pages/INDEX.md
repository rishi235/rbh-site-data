# Branch landing pages - paste manifest

Shared-domain split (item 2.2): each branch on a shared website gets its own
local landing page. Paste each file into a Weebly Embed Code element on the
matching URL and set the Weebly page SEO title and description.

Suggested Weebly placement: top-level pages, one per branch, linked from the
site navigation (e.g. "Ainsdale branch" / "Eccleston branch").
